# AI Business Transformation

## はじめて見る方へ

**[公開サイト](https://ai-business-transformation-nine.vercel.app)** / **[主要成果物の案内](https://github.com/Josh-Temple)** / **[実務Method](methods/INDEX.md)**

地方自治体での実務を背景に、AIをどの作業へ組み込み、どこを標準化し、誰が確認するかを考える個人の知見発信です。問題設定、業務設計、human-in-the-loop、品質・効果測定の判断基準を、公開プロジェクトと接続して整理しています。

**確認上の限界:** 初期コンテンツです。顧客へのコンサルティングやAI導入の実績、定量的な業務効果を示すものではありません。個人活動と所属組織の業務成果は区別します。

AIを使って業務をどう再設計し、成果につなげるかを扱うプロジェクトです。

このサイトは、AIニュースやツール紹介を大量に掲載する一般的なAIメディアではなく、実務上の課題を起点に、業務分析、AI導入、運用、品質管理、効果測定までを考える「コンサルティング型の知見発信」を目指します。

## Current concept

中心となる考え方は次のとおりです。

> 実務で得た知見を起点に、一次資料・研究・企業事例などをAIを使って調査し、検証・比較した上で、他の組織にも応用できる条件や判断基準へ一般化する。

扱う内容の中心は、当面以下を想定しています。

- AI活用と業務改革
- BPR / 業務プロセス設計
- AI導入・PoC・本番運用
- AIガバナンス、品質管理、人間による確認
- AI導入効果・KPI・ROI
- AIエージェントと業務設計
- 実際のケーススタディと失敗から得た知見

詳細は [docs/PROJECT_CONCEPT.md](docs/PROJECT_CONCEPT.md) を参照してください。

実務Methodの入口は [methods/INDEX.md](methods/INDEX.md) にまとめています。

想定読者とポジショニングの仮説は [docs/AUDIENCE_POSITIONING.md](docs/AUDIENCE_POSITIONING.md) に整理しています。
